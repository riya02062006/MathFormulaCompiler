
MATHEMATICAL FORMULA COMPILER
CONTEXT-FREE GRAMMAR
====================

1. ORIGINAL GRAMMAR

E -> E + T | E - T | T
T -> T * U | T / U | U
U -> + U | - U | P
P -> A ^ U | A
A -> ID | NUMBER | (E) | sqrt(E) | pow(E,E)


2. GRAMMAR AFTER ELIMINATING LEFT RECURSION

E  -> T E'
E' -> + T E' | - T E' | epsilon

T  -> U T'
T' -> * U T' | / U T' | epsilon

U  -> + U | - U | P

P  -> A P'
P' -> ^ U | epsilon

A  -> ID | NUMBER | (E) | sqrt(E) | pow(E,E)


3. TERMINAL SYMBOLS

ID      : Variable name
NUMBER  : Numeric constant
+       : Addition
-       : Subtraction
*       : Multiplication
/       : Division
^       : Exponentiation
sqrt    : Square-root function
pow     : Power function
( )     : Parentheses
,       : Argument separator

epsilon : Empty production
